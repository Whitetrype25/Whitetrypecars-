# White Trype Cars App

Aplicación móvil inicial basada en React Native/Expo para la potenciación de vehículos.

## Características
- Introducción de referencia de ECU o archivo original.
- Detección básica del método de lectura (OBD o Bench/Boot).
- Selección de Stage 1, Stage 2 o Stage 3 con precios de 50€, 120€ y 180€.
- Mensajes con requisitos y advertencias para Stage 3.
- Ejemplo de envío de solicitud que muestra un resumen.

Este es un punto de partida; la generación real de archivos mediante IA y la integración de pagos deben implementarse.
